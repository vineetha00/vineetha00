## What I'm building

**[promptops](https://github.com/vineetha00/promptops)** — Git-native version control for LLM prompts. Semantic diff, Thompson Sampling A/B testing, LLM-as-judge regression evals, MCP server, GitHub Actions CI gate. `pip install promptops`

**[agentaudit](https://github.com/vineetha00/agentaudit)** — "git blame" for multi-agent LLM pipelines: failure attribution, handoff scoring, loop detection, and cost guardrails.

**[SynapNet-Edge](https://github.com/vineetha00/SynapNet-Edge)** — efficient long-context inference on consumer hardware via a quantized hybrid SSM + sparse-attention + episodic-memory architecture. Reproducible in 25 min on a MacBook. ([architecture repo](https://github.com/vineetha00/SynapNet_Exp))
